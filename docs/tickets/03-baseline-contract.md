# eval: 版本化基线契约、可执行容差及完整指标

## Parent
Part of #51（#41 修正）

## What to build
以受校验的新格式建立和比较基线：包含原有核心指标、页数达成率、需求覆盖率、有效样本与来源，诊断性保存幻觉/重试。旧基线显式待重建，不能伪造新测量值。

## Acceptance criteria
- [ ] 记录格式版本、题集版本、题数、来源 run/代码提交/运行条件/时间。
- [ ] 新增页数达成率和需求覆盖率检查；保存幻觉、重试诊断。
- [ ] 数值容差真正参与比较，缺指标/无样本/无 Trace/无来源时拒绝正式基线。
- [ ] 从 DB 立基线保留当次运行元数据，不用当前配置冒充历史配置。
- [ ] 本次只做离线测试，历史 baseline 标为待重建，不调用真实模型。
