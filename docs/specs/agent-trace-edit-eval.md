# Agent 工具轨迹与固定页面编辑评测

Parent: #42；延续现有 PR #50。

## 已确认范围
- 工具调用统一入口，记录轮次、调用 ID、顺序、目标块、结果和耗时；沿用 traces/spans PostgreSQL 持久化和瀑布树。
- 生成侧修复收敛指标必须依据明确校验结果，不能把未修复或任务 succeeded 直接当成合法。
- 编辑评测移除大纲/正文/图片生成。题集保存固定初始 blocks、layout_tree、locked 状态和明确预期。
- 真实评测仅 AI 编辑调用真实模型，程序规则评分不调用 judge。
- 本次只运行无模型的单元/集成测试，不运行真实评测，不需要或索取 Token。
- checkpoint、快照恢复、分叉、真实质量基线、编辑指标硬门禁不在本次范围。

## 验收
1. 固定夹具及期望通过 schema/布局引用校验；稳定哈希纳入初始页面全部内容，文件顺序/运行环境不影响版本。
2. 执行器直接在隔离项目准备固定页，无 outline/generate、deck/generate 或生图调用；仅调用 ai-edit，并保存关联 trace。
3. 规则检查操作类型、目标 ID、操作数量下限/上限、指定结果、locked 与非目标块不变；必要时对提案应用后的副本验证结构/布局。不把关键词出现在错误块当成功，不把应修改题的零操作当成功。
4. 工具的结构化公共轨迹入口记录成功、拒绝、未知工具、异常；保留原工具参数接口和业务行为，不记录正文或完整参数。
5. 修复页去重；失败页不算首过；缺少校验证据返回不可判定。报告与 API 共用统计口径。
6. 编辑报告和生成报告明确区分，编辑报告详情可读、可查 Trace，不将未采集 Token/成本展示成真实零，也不进入生成基线。
7. 与最新 main 集成并保留 #56 的 Trace 完整性和可信基线规则。
8. 确定性 pytest、数据库/API 回归、Ruff、前端类型/build、双轴评审与 Archify 验收后更新 PR。

## 测试边界
题集加载/版本；编辑评分公开函数；编辑执行器+HTTP/数据库边界；真实工具循环+假模型；Trace 聚合/API；报告 API 序列化。只 mock 模型、HTTP 等外部边界，不调用真实模型。
